## Verdict

The **4.8% figure is conditional, not a general upper limit on the LMC RR Lyrae binary fraction**. It depends on the assumed binary population, recovery efficiency, and amplitude-veto correction. There is also a reproducibility mismatch: the checked-in script calculates the uncorrected limit but does not generate the CSV’s `f_max_alpha_corrected` column. [upper_limit_v4.py:55–66](/Users/vasilybelokurov/IoA%20Dropbox/Dr%20V.A.%20Belokurov/Code/rrl_lmc_binary/scripts/upper_limit_v4.py:55) [upper_limits.csv:1–4](/Users/vasilybelokurov/IoA%20Dropbox/Dr%20V.A.%20Belokurov/Code/rrl_lmc_binary/results/partB_v4/upper_limits.csv:1)

The arithmetic behind the claimed result is straightforward: for the 0.4–1.5 M☉, 1,000–10,000 d bin, the CSV has ε = 0.568 and an uncorrected limit of 2.94%; dividing by 0.609 gives 4.83%. [upper_limits.csv:4](/Users/vasilybelokurov/IoA%20Dropbox/Dr%20V.A.%20Belokurov/Code/rrl_lmc_binary/results/partB_v4/upper_limits.csv:4) But neither that correction nor the resulting limit is justified for an unspecified binary population.

## Main issues, ranked

1. **The amplitude-veto correction is not reproducible from the script, and the relevant pass rate is unclear.** The script estimates `a_pass` among real stars that pass the *other four cuts*, then uses it for the empirical-noise background; it does not apply that factor to the binary efficiency or write an alpha-corrected limit. [upper_limit_v4.py:46–49, 55–66](/Users/vasilybelokurov/IoA%20Dropbox/Dr%20V.A.%20Belokurov/Code/rrl_lmc_binary/scripts/upper_limit_v4.py:46) The CSV’s corrected value instead corresponds to dividing by 0.609. [upper_limits.csv:4](/Users/vasilybelokurov/IoA%20Dropbox/Dr%20V.A.%20Belokurov/Code/rrl_lmc_binary/results/partB_v4/upper_limits.csv:4) Yet the journal records an alpha pass rate of 0.39 among real stars passing the other cuts, with 239 such stars and 93 passing all cuts. [JOURNAL.md:832–837](/Users/vasilybelokurov/IoA%20Dropbox/IoA%20Dropbox/Dr%20V.A.%20Belokurov/Code/rrl_lmc_binary/JOURNAL.md:832) [JOURNAL.md:879–884](/Users/vasilybelokurov/IoA%20Dropbox/IoA%20Dropbox/Dr%20V.A.%20Belokurov/Code/rrl_lmc_binary/JOURNAL.md:879) These figures are not interchangeable: 61% unconditional alpha passage does not establish the passage rate for stars otherwise detectable. Using 0.39 as a sensitivity calculation would make the limit about 7.5%, rather than 4.8%; that is **not** itself a justified correction, because the relevant quantity is alpha passage for real binaries conditional on their detectability. Fix: calculate recovery for injected binaries with amplitude variability represented jointly with timing noise, then estimate the pass probability for the target binary population. Until then, report the 4.8% only with its explicit 0.609 assumption.

2. **The binary recovery simulations omit the intrinsic timing noise that the analysis says real stars have.** `ltte` draws set orbital parameters and then simulate the orbit; the separate `empirical` branch adds red timing noise and season jitter. The code does not combine those branches for binary injections. [inject_recover.py:80–88](/Users/vasilybelokurov/IoA%20Dropbox/Dr%20V.A.%20Belokurov/Code/rrl_lmc_binary/scripts/inject_recover.py:80) [level1_sims.py:53–75](/Users/vasilybelokurov/IoA%20Dropbox/IoA%20Dropbox/Dr%20V.A.%20Belokurov/Code/rrl_lmc_binary/scripts/level1_sims.py:53) The journal itself notes that the completeness is measured with photometric noise only and that red timing noise could lower it. [JOURNAL.md:855–868](/Users/vasilybelokurov/IoA%20Dropbox/IoA%20Dropbox/Dr%20V.A.%20Belokurov/Code/rrl_lmc_binary/JOURNAL.md:855) Lower recovery means a **higher** fraction limit; the size is unmeasured. Fix: inject LTTE into the empirical red-noise realizations on the same stars, rerun the cuts, and report the resulting efficiency and uncertainty. The “400 s typical red noise” comparison in the journal is not a measured bound on the efficiency change. [JOURNAL.md:867–868](/Users/vasilybelokurov/IoA%20Dropbox/IoA%20Dropbox/Dr%20V.A.%20Belokurov/Code/rrl_lmc_binary/JOURNAL.md:867)

3. **The result is averaged over a specific injected population; it is not a limit for every companion in the quoted mass and period ranges.** The draws use log-uniform companion mass and period, isotropic inclinations, and an eccentricity mixture with half circular and half drawn below 0.7. [inject_recover.py:80–87](/Users/vasilybelokurov/IoA%20Dropbox/IoA%20Dropbox/Dr%20V.A.%20Belokurov/Code/rrl_lmc_binary/scripts/inject_recover.py:80) The script averages `all` within each requested bin. [upper_limit_v4.py:53–63](/Users/vasilybelokurov/IoA%20Dropbox/IoA%20Dropbox/Code/rrl_lmc_binary/scripts/upper_limit_v4.py:53) Thus 4.8% applies only if the actual systems have a distribution sufficiently like those draws within the bin. A population concentrated where recovery is lower weakens the limit; the within-bin change is not established by the aggregate CSV. Fix: publish narrow-bin efficiencies or a likelihood using a stated population model; for a model-independent bound, use a justified lower bound on efficiency across the target region.

4. **The count limit is a reasonable conservative approximation, but not a complete uncertainty calculation.** The script treats all 93 candidates as binaries and uses a classical Poisson upper mean of 110.5; that is conservative with respect to subtracting a nonnegative background, but it still assumes the count model and a known efficiency. [upper_limit_v4.py:26–29, 44–51](/Users/vasilybelokurov/IoA%20Dropbox/IoA%20Dropbox/Code/rrl_lmc_binary/scripts/upper_limit_v4.py:26) The CSV’s N is 6,612 and k is 93. [upper_limits.csv:4](/Users/vasilybelokurov/IoA%20Dropbox/IoA%20Dropbox/Code/rrl_lmc_binary/results/partB_v4/upper_limits.csv:4) Replacing the Poisson approximation with an exact binomial bound is unlikely to materially change this low detection-probability result; uncertainty in efficiency and the alpha correction matters more. Fix: calculate the binomial signal bound and propagate finite-injection uncertainty in ε. The MC sample for this bin is 1,532 injections. [upper_limits.csv:4](/Users/vasilybelokurov/IoA%20Dropbox/IoA%20Dropbox/Code/rrl_lmc_binary/results/partB_v4/upper_limits.csv:4)

5. **The denominator defines a MACHO-available subsample, not all LMC RR Lyrae.** The script selects `has_M` rows and removes error rows when that column exists. [upper_limit_v4.py:40–45](/Users/vasilybelokurov/IoA%20Dropbox/IoA%20Dropbox/Code/rrl_lmc_binary/scripts/upper_limit_v4.py:40) So the stated N=6,612 supports a claim about that analyzed sample; applying the fraction to all LMC RR Lyrae requires showing that this sample represents the broader population. The simulations also draw MACHO-ID stars and then sample up to 1,500 of them. [level1_sims.py:125–137](/Users/vasilybelokurov/IoA%20Dropbox/IoA%20Dropbox/Code/rrl_lmc_binary/scripts/level1_sims.py:125) Fix: state the target sample explicitly or calibrate efficiency and counts across the intended full sample.

6. **The code has little direct test coverage for the limit calculation.** Tests cover toy behavior of `cut_flags` and reproducing an older candidate list, but I found no test for `upper_limit_v4.py`, its `k95` calculation, or consistency of its output schema with the CSV. [test_partC.py:11–26](/Users/vasilybelokurov/IoA%20Dropbox/IoA%20Dropbox/Code/rrl_lmc_binary/tests/test_partC.py:11) Fix: add deterministic checks for the count limit, efficiency binning, alpha correction, and generated CSV columns.

The files do not establish these assumptions.

## Strongest argument against this assessment

The all-candidates-as-binaries count bound is deliberately conservative, and the target high-mass, multi-year orbits have substantial recovery in the simulations. [upper_limit_v4.py:44–51](/Users/vasilybelokurov/IoA%20Dropbox/IoA%20Dropbox/Code/rrl_lmc_binary/scripts/upper_limit_v4.py:44) [upper_limits.csv:4](/Users/vasilybelokurov/IoA%20Dropbox/IoA%20Dropbox/Code/rrl_lmc_binary/results/partB_v4/upper_limits.csv:4) If the 0.609 factor really is the alpha-pass probability for detectable binaries, and if red noise and the assumed intra-bin population have little effect, then 4.8% is a defensible conditional limit. The weakness is that those conditions are not demonstrated by the current calculation.
